# JavaScript: билетная касса

Практическое задание по первым трём лекциям курса Frontend разработки ИТМО. Основная тема — [«Функции»](https://itmo-frontend-lectures.vercel.app/1-sem/js/3-functions/index.html).

Напишите функции для расчёта стоимости, выдачи и печати билетов. Проверяйте работу вызовами функций в консоли.

## Часть 1. Расчёт стоимости

Реализуйте `calculateTotal(price, quantity, discountFn)`.

Функция рассчитывает стоимость всех билетов и применяет к полученной сумме функцию скидки. Если `discountFn` не передана, возвращает полную стоимость.

Реализуйте `createDiscount(percent)`, которая возвращает функцию, уменьшающую переданную сумму на указанный процент.

```js
const studentDiscount = createDiscount(20);

calculateTotal(1000, 2);                  // 2000
calculateTotal(1000, 2, studentDiscount); // 1600
calculateTotal(1000, 0, studentDiscount); // 0
```

Функции расчёта должны возвращать результат без изменения внешних данных и без вывода в консоль внутри функции.

## Часть 2. Выдача билетов

Реализуйте `createTicketOffice(eventName, capacity)`.

Она возвращает функцию, принимающую имя покупателя. При каждом успешном вызове эта функция выдаёт новый объект билета:

```js
const sellTicket = createTicketOffice("Frontend Meetup", 2);

sellTicket("Анна");
// { event: "Frontend Meetup", number: 1, name: "Анна" }

sellTicket("Иван");
// { event: "Frontend Meetup", number: 2, name: "Иван" }

sellTicket("Мария");
// null — свободных мест больше нет
```

Количество выданных билетов храните в замыкании. Нумерация начинается с единицы. Каждая созданная касса должна иметь собственный независимый счётчик. После заполнения кассы все последующие вызовы возвращают `null`.

## Часть 3. Печать билета

Реализуйте `print(ticket)`, которая принимает выданный билет и выводит в консоль сообщение следующего формата:

```text
Билет №1
Мероприятие: Frontend Meetup
Покупатель: Анна
```

Если передан `null`, функция выводит:

```text
Билеты закончились.
```

Требования к `print`:

- Выводит сообщение одним вызовом `console.log`.
- Не изменяет переданный объект.
- Не выдаёт новый билет и не изменяет состояние кассы.
- Возвращает `undefined`.

Пример совместного использования:

```js
const sellTicket = createTicketOffice("Frontend Meetup", 1);
const ticket = sellTicket("Анна");

print(ticket);               // Печатает билет №1.
print(ticket);               // Повторно печатает тот же билет.
print(sellTicket("Иван"));    // Билеты закончились.
```

## Входные данные

Считаем входные данные корректными:

- цена неотрицательная;
- количество билетов и вместимость — целые неотрицательные числа;
- скидка — от 0 до 100;
- имя — непустая строка;
- в `print` передаётся объект выданного билета либо `null`.

## Обязательные проверки

- Расчёт без скидки, со скидкой 20% и со скидкой 100%.
- Покупка нуля билетов.
- Выдача последнего доступного билета и попытка выдать следующий.
- Касса с нулевой вместимостью.
- Две кассы: выдача билета в одной не влияет на другую.
- Печать билета и сообщения об отсутствии мест.
- Повторная печать не меняет билет и количество свободных мест.
