Где используется замыкание и что в нём хранится?
В скидке хранится процент, в кассе название, вместимость и свой счётчик билетов

Какие функции являются чистыми?
createDiscount, функция скидки и calculateTotal с чистой скидкой, тк они не меняют внешние данные и ничего не печатают

Почему print работает без return с результатом?
print выводит текст через console.log, без return она возвращает undefined





Ожидаемые результаты проверок:

Расчёты по порядку: 2000, 1600, 0, 0
Первый билет: { event: "Frontend Meetup", number: 1, name: "Анна" }

Оба вызова print(firstTicket) печатают один и тот же текст:
Билет №1
Мероприятие: Frontend Meetup
Покупатель: Анна

После печати первый билет остаётся тем же объектом с теми же данными
Последний билет: { event: "Frontend Meetup", number: 2, name: "Иван" }
Покупки Марии и Олега возвращают null. Печать результата покупки Евы выводит: Билеты закончились

Касса без мест возвращает null

В независимых кассах выдаются билеты: «Лекция», №1, Анна; «Лекция», №2, Иван; «Концерт», №1, Мария
