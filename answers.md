# Ответы на вопросы

1. Замыкания используются в `createTicketOffice` и `createDiscount`. Возвращённая кассой функция запоминает `eventName`, `capacity` и `soldTickets` название мероприятия, вместимость и число уже выданных билетов. Параметр `percent` запоминает функция скидки, возвращённая из `createDiscount`. Кассы не делят счетчик, так как при каждом вызове фабрики создаётся собственное окружение.

2. `calculateTotal` не меняет внешние данные и возвращает результат вычисления. Чистая, если переданная функция скидки тоже чистая. `createDiscount` не имеет побочных эффектов, а возвращённая ею функция только рассчитывает сумму по сохранённому проценту. Функция продажи билетов изменяет счётчик кассы, а `print` имеет побочный эффект - выводит сообщение в консоль.

3. `print` нужна для вывода сообщения. Поэтому ей не нужно возвращать значение без `return` JavaScript возвращает `undefined`.
